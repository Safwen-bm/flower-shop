# OneFlower

A responsive landing page for an online flower shop. Built with plain HTML and CSS, no framework needed.

## Features

- Hero section with a scrolling ticker
- About section with a background video
- Service highlights: free delivery, returns, gifts, secure payments
- Product grid with discount badges and hover actions
- Customer reviews, contact form and closing call to action
- Responsive layout with a mobile menu

## Tech stack

HTML5, CSS3, Font Awesome, Google Fonts (Fraunces, DM Sans)

## Getting started

No install needed. Download or clone the repo, then open `index.html` in your browser.

```
git clone https://github.com/Safwen-bm/flower-shop.git
cd flower-shop
```

## Project structure

```
index.html       page markup
styles/          style.css
images/          photos, icons, logo and video
```

## Notes

The contact form is not connected to a backend yet. Connect it to a service like Formspree to receive real messages.
